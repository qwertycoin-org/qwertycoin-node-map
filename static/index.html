How to read this map

Based on connections observed by one Qwertycoin node. This is a partial network view. IP locations are approximate; one IP does not necessarily represent one node.

Each public IP seen at least once in the selected period is counted once. Only a keyed, non-public deduplication token, first/last-seen times, country and rounded map point are retained for 30 days; raw IPs are never persisted.
